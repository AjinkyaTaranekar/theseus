Pull requests

Every pull request Theseus reviewed, newest first. A blocked PR cannot merge until its review is clear.

Security findings

Advisories that affect a workflow on main, checked on every push to main and every night. Each one says what a compromised workflow could reach, where to cut it off, and which secrets to rotate.

Who reaches what on main

The blast radius of each person, workflow and service: the sensitive data it could reach today if it were compromised. Dashed items are access a requirement in theseus.yaml asks for.

Weak points

Single points of failure

On every route of something a service or person needs. If it breaks or is deleted, all of these stop working.

Articulation points

Removing it splits the access graph in two or more pieces.

Choke points

Roles the most routes pass through, by betweenness. Tightening one protects the most paths.

Grants no code uses

Access a service holds but its code never calls. Removing it costs nothing.
