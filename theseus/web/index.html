How it works

  1. 1

    Build the graph

    The plan, the code and the PR text become one FalkorDB graph per commit. Every edge cites its line.

  2. 2

    Find the path

    Cypher traces every route to sensitive data. Max flow asks whether one cut can close them all.

  3. 3

    Prove the fix

    Each fix runs on its own GRAPH.COPY. Only one that closes every path and breaks nothing reaches you.

On every pull request

  1. 1

    Reviews

    A required Theseus check and one comment: what the PR asked for, what it would grant, every hop cited.

  2. 2

    Suggests

    The fix that passed, as suggested changes on the PR's own lines.

  3. 3

    Applies

    A reviewer comments /theseus apply. The App commits the fix and reviews again.

Built for agentic development

Your coding agent asks the graph before it ships.

  1. 1

    Install the plugin in Claude Code

    /plugin install theseus --marketplace AjinkyaTaranekar/theseus
  2. 2

    Point it at your Python

    export THESEUS_PYTHON=.venv/bin/python
  3. 3

    Check a change before the PR

    /theseus:check give priya read access to the logs
  4. 4

    Ask the graph anything

    /theseus:investigate what if casey-contractor is compromised?
  5. 5

    Or any MCP client: ten graph tools

    python -m theseus.mcp.server --repo .

The theseus skill tells the agent when to check and how to report: facts only from the tools, every hop cited, UNKNOWN kept. Its hook stops git commit, git push and gh pr create once when a change opens a path to sensitive data.
