## Why

A sender-only change would repeat alerts: the existing `save_finding` replaces the document and drops a
new `notified` flag. A SecretStr-only change would also leak the webhook through HTTPX INFO request logs.
Both were reproduced offline. The engine's real compromised-action result matches two workflows but only
one has reported dangerous opened paths, so the message must not attribute the union to each workflow.

The issue leaves urgency cutoff and retry semantics unsettled. Resolve those before product code, as
AGENTS.md requires for new rules. Preserve the approved engine/model/human boundary and the merged #149
policy: a passing but vetoed K can still open a proposal with an explicit closer-review warning.
