# A5: Real analyze behind the Action

**Lane:** Agent and GitHub | **Stage:** Beat 1: See it | **Size:** S | **Needs first:** E3, A3, A4, F7 | **Branch:** `a5-real-analyze`

## The feature

`POST /analyze` with a repo runs the real pipeline: read the world root at both SHAs and the PR's current title and body, build both worlds, `run_pr`, render, update the comment and check. The check's conclusion and plain-words title follow 07, "Blocking a merge".

## Why it matters

The last piece before Gate 1: the intern PR shows three opened paths and says versus grants, live.
