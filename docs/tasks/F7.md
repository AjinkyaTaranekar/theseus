# F7: GitHub Action and App skeleton

**Lane:** Foundation | **Stage:** Foundation | **Size:** M | **Needs first:** F2, F3 | **Branch:** `f7-action-app`

## The feature

The Theseus Action at the repo root, a registered GitHub App installed on this repo, and backend code that posts or updates one PR comment and a check run.

## Why it matters

The walking skeleton: a demo PR gets a comment from the live URL. After this, every task shows up on a real PR.

## Files

| File | Action | Purpose |
| --- | --- | --- |
| `.github/workflows/theseus.yml` | create | On `pull_request` (`opened`, `synchronize`, `reopened`, `edited`) with `paths: ["demo-infra/**"]` and one run per PR at a time; the five steps in 07, planning in `demo-infra/terraform`. Title and body passed through `env:`, never inlined in `run:` |
| `theseus/api/github.py` | create | App JWT, installation token, read files under the world root at a SHA, upsert the comment by marker, create or update the `Theseus` check run, re-run the latest Theseus workflow run for a head SHA |
| `theseus/api/routes.py` | change | With `repo` in the body: build the stub result and post it through `github.py`. The webhook: `/theseus review` and a check `rerequested` re-run the workflow; a PR that changes nothing under the world root gets a `success` check |
| `tests/unit/test_github.py` | create | respx-mocked GitHub API: the comment is created once and then edited; the check run gets the headline; `/theseus review` and a rerequested check re-run the workflow; a PR outside the world root gets a `success` check |

## Steps

1. Register the App with the permissions and events in 07 and install it on this repo only.
2. Set `THESEUS_URL` (a repo variable) and `THESEUS_TOKEN` (a secret).
3. Open a trial PR on branch `demo/trial-1` that edits a comment in `demo-infra/terraform/people.tf`, with label `demo`.
4. A person creates the ruleset on `main` that requires the `Theseus` check from the App (07, "Blocking a merge").
5. Try requesting a review from the App on the trial PR, and record in 07 whether GitHub allows it.

## Done when

- [ ] The trial PR gets a stub comment from the live URL
- [ ] A `Theseus` check run appears
- [ ] A PR that touches no file in `demo-infra/` does not run the Action, and gets a `success` `Theseus` check
- [ ] `/theseus review` and Re-run on the check each start a new review
- [ ] A stub result with an opened path fails the check, and the merge box says the merge is blocked
- [ ] `pytest -q` and `ruff check .` pass, and `AI_USE.md` has this task's line
