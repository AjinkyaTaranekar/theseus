# C4: Use beyond intent

**Lane:** Code-aware | **Stage:** Beats 3 and 4: Contain it, Nobody breaks | **Size:** S | **Needs first:** C2, A3 | **Branch:** `c4-beyond-intent`

## The feature

Flag new code calls to sensitive data that no `theseus.yaml` requirement covers, even when the PR's text mentions them, and use the second headline form.

## Why it matters

"Your PR says: fix a typo. Your code now reads customer-db." It needs only the code reader and the headline, so it runs beside C3, not after it.
