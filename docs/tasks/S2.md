# S2: Proof: benchmark against Checkov, and large-graph timings

**Lane:** Story and proof | **Stage:** Ship | **Size:** L | **Needs first:** E4, E5 | **Branch:** `s2-proof`

## The feature

About 20 PR cases built from the demo world, Theseus and Checkov run on each, and a table of catches and misses; plus a synthetic world with thousands of nodes, timing the path query, `GRAPH.COPY`, max flow and one simulation.

## Why it matters

Answers "how accurate is it?" and "does it scale?" with numbers, including our misses. Both live in `bench/` and run on the VM.

## Files

| File | Action | Purpose |
| --- | --- | --- |
| `bench/cases/<id>/` | create | Same layout as fixtures; humans write each `expected.json`; include public patterns (missing OIDC `sub`, public buckets, wildcards, an analyst given `raw/`) |
| `bench/run.py` | create | Runs the engine on every case and compares projections |
| `bench/checkov.py` | create | Runs Checkov on each head and records pass or fail |
| `bench/scale.py` | create | Generates worlds of 1,000 and 10,000 edges, times each step five times, writes medians |
| `bench/report.md` | generate | The table: case, Theseus found, Checkov found, expected; then the timings |
