## Steps

1. One service at a time, in the order of the 02 table; 40 to 150 lines a module.
2. Every resource name comes from an environment variable read at module level; clients from `boto3.client(...)`.
3. Run `tools/plan.sh` after adding `network.tf` and `platform.tf`; the modeled files must not change.
4. Regenerate the fixtures.

## Done when

- [ ] Every resource name in the code comes from an environment variable

- [ ] Every golden test that exists still passes on the regenerated fixtures
