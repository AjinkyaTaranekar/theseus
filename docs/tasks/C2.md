# C2: Python code reader

**Lane:** Code-aware | **Stage:** Beat 2: Fix it | **Size:** L | **Needs first:** F2, C1 | **Branch:** `c2-code-reader`

## The feature

Read the service code with Python's `ast` and add `CALLS`, `REQUESTS` and `HAS_ENV` edges with file and line, resolving names through module constants and each workload's Lambda or ECS environment; count calls to services Theseus does not model.

## Why it matters

The third source of truth. Without it, Beat 4 does not exist.
