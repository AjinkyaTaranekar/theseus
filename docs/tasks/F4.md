# F4: Demo world and fixture generator

**Lane:** Foundation | **Stage:** Foundation | **Size:** L | **Needs first:** F1 | **Branch:** `f4-demo-world`

## The feature

`demo-infra/`: the modeled Terraform, the fictional org's workflows, `theseus.yaml` and empty service folders, exactly as in spec 02; `tools/plan.sh`; and `tools/make_fixture.py`, which builds the five fixture folders from `demo-infra/`.

## Why it matters

Every fixture, golden test and demo PR starts here, and it is on the critical path: E1 waits for the fixture folders. It needs no contracts, so it starts the moment F1 merges, in parallel with F2.

## Steps

1. Write the Terraform from the 02 tables, one file at a time, `people.tf` first.
2. Run `tools/plan.sh demo-infra/terraform /tmp/main.plan.json` after each file; fix anything plan rejects under mock credentials.
3. Write the workflows and `theseus.yaml`, then `make_fixture.py`, then generate the fixtures.
4. Tell both humans the line numbers are final, so F5 can start.

## Done when

- [ ] `terraform plan` gives JSON for `demo-infra/terraform` with no AWS account
- [ ] Every modeled resource in 02 is present with its exact name
- [ ] No modeled field is unknown in the plan
- [ ] Four fixture folders are generated and committed
- [ ] `pytest -q` and `ruff check .` pass, and `AI_USE.md` has this task's line
