# C3: Unused grants, with usage capacities

**Lane:** Code-aware | **Stage:** Beats 3 and 4: Contain it, Nobody breaks | **Size:** M | **Needs first:** C2, E4, E5 | **Branch:** `c3-unused-grants`

## The feature

`CAN` edges backed by a code call get capacity `USED`, so the cut lands on grants nobody uses; `calls_broken` becomes real in verdicts; scan mode lists grants on dangerous paths that no code calls and proves candidate U for each.

## Why it matters

Beat 4's finding: support-portal may read the database secret and never does, and the fix breaks nobody. The usage capacity and the scan share one golden test, so one session does them.
