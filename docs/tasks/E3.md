# E3: Graph load, path diff and required access

**Lane:** Engine | **Stage:** Beat 1: See it | **Size:** M | **Needs first:** E1, E2, F3, F5 | **Branch:** `e3-analyze`

## The feature

Load rows into FalkorDB (one graph per state), find valid paths, decide dangerous paths and requirement status, diff base against head, and produce a first `AnalysisResult` from `python -m theseus analyze`.

## Why it matters

This is Beat 1's engine: the three opened paths for the intern, and the six already in `main`.
