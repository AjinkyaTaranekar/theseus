# A1: LLM intent extraction

**Lane:** Agent and GitHub | **Stage:** Beat 1: See it | **Size:** M | **Needs first:** F2 | **Branch:** `a1-intent`

## The feature

The single wrapper for every LLM call (record, replay, live), and intent extraction: PR text to the access it says it needs.

## Why it matters

"Your PR says logs" needs a reliable reading of what the PR says. The PoC scored 10 of 10 with this prompt on
Claude; this task checks it on GLM 5.3.

## Files

| File | Action | Purpose |
| --- | --- | --- |
| `theseus/agent/llm.py` | create | `Llm(settings).call(purpose, messages, tools, tool_choice, fast=False) -> LlmReply` over LiteLLM, with the three modes, retries and the recording key; `untrusted(tag, text)` fences outside text so it cannot close its own tag |
| `theseus/agent/screen.py` | create | `normalize`, `mask_secrets`, `injection_flags`: hygiene for any untrusted text before a model reads it |
| `theseus/agent/pr_text.py` | create | `prepare(title, body, template)`: hidden comments and tag-character text set apart (minus the template's own comments), template lines, empty sections and unticked boxes dropped, secrets masked, screen flags kept, nothing cut |
| `theseus/agent/intent.py` | create | Schema, vocabulary from the head graph, prompt, `extract_intent(pr_title, pr_body, vocab, *, llm, template="") -> Intent` (grants outside the vocabulary are dropped; no grants when `stated` is false; an empty PR is not sent; a screen flag makes it suspicious; the purpose is plain text), `to_requirements(intent) -> list[Requirement]` |
| `tests/replay/intents.yaml` | humans write | 31 PR texts with gold grants: spec 02's PR scenarios, more on the demo world (an analyst asking for `raw/`), and real-world mess: a filled and a blank PR template, a title alone, a vague title, a conventional-commit title, a bot bump, two injections, one hidden in an HTML comment, and 12 red-team attacks (fake tags, role-play, a changed vocabulary, JSON breakout, look-alike letters, base64, Spanish, Chinese, typos, a config block, padding, tag characters) with two benign look-alikes |
| `recordings/llm/intent-*.json` | record | One live run per case at the gate, saved by `THESEUS_MODE=record` |
| `tests/replay/test_intent.py` | create | Replays every case; exact match on grants; the injection case sets `suspicious` |

## Steps

1. Read the current LiteLLM docs for tool calling and exceptions first.
2. Write `llm.py` with replay as the default, then `intent.py`.
3. Record once with the Crusoe key, commit the recordings, and confirm the tests pass offline. If GLM 5.3 misses
   cases the PoC passed, report which ones in the PR before changing the prompt or the model.
