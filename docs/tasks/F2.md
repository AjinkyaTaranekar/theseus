# F2: Freeze the contracts

**Lane:** Foundation | **Stage:** Foundation | **Size:** M | **Needs first:** F1 | **Branch:** `f2-contracts`

## The feature

`theseus/contracts/`: the graph schema constants, every shared Pydantic model, `project()` and `compare()` for golden tests, and the engine function signatures. Written together, then frozen.

## Why it matters

Both lanes code against these once they are frozen. A contract that changes later breaks the other person's work.

## Files

| File | Action | Purpose |
| --- | --- | --- |
| `theseus/contracts/schema.py` | create | Label names, `EDGE_TYPES`, `TRAVERSE` (`MEMBER_OF`, `CAN_ASSUME`, `TRUSTS`, `RUNS_AS`), `GRANT` (`CAN`, `UNLOCKS`), edge kinds, resource kinds (`s3`, `secret`, `db`, `dynamodb`), `MODELED_TYPES` (the list in 04 section 1), `node_id(kind, name)` and `parse_id(id)`, `BIG = 1_000_000`, `USED = 1_000`, `MAX_PATH_EDGES = 7`, `CANDIDATE_IDS` |
| `theseus/contracts/result.py` | create | Every model in the 05 table, including `Coverage`. `PathStep` serializes `src` and `dst` as `from` and `to`. `project(result) -> dict` in the `expected.json` shape. `compare(projection, expected, keys=None) -> list[str]` returns readable differences, comparing only keys present in `expected` (or in `keys`) |
| `theseus/contracts/engine.py` | create | `typing.Protocol` classes for the graph store and each engine function in the 05 table, with docstrings. No implementations |
| `tests/contract/test_models.py` | create | Round-trip an `AnalysisResult` through JSON; `PathStep` uses `from` and `to`; `project()` of a hand-built result equals a hand-written projection; `compare()` reports a changed verdict and ignores fields missing from `expected` |

## Steps

1. Write `schema.py` first, then `result.py`, then `engine.py`.
2. Both humans read every field name aloud against the spec before merging.
3. Merge, and announce the freeze.

## Done when

- [ ] Both humans reviewed and approved
- [ ] The freeze is announced
- [ ] `tests/contract/` passes
- [ ] `pytest -q` and `ruff check .` pass, and `AI_USE.md` has this task's line
