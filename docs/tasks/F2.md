# F2: Freeze the contracts

**Lane:** Foundation | **Stage:** Foundation | **Size:** M | **Needs first:** F1 | **Branch:** `f2-contracts`

## The feature

`theseus/contracts/`: the vendor-neutral graph schema, every shared Pydantic model, `project()` and `compare()` for golden tests, the engine function signatures, and the adapter protocols that keep AWS, Terraform, GitHub and Python out of the core. Written together, then frozen.

## Why it matters

Both lanes code against these once they are frozen. A contract that changes later breaks the other person's work.

## Steps

1. Write `schema.py` first, then `result.py`, then `engine.py`.
2. Both humans read every field name aloud against the spec before merging.
3. Merge, and announce the freeze.

## Done when
