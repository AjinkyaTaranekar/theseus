# A4: PR comment: paths, fix table, trace and coverage

**Lane:** Agent and GitHub | **Stage:** Beat 1: See it | **Size:** L | **Needs first:** F2 | **Branch:** `a4-comment`

## The feature

Render an `AnalysisResult` as the whole PR comment: headline, opened paths with Mermaid diagrams and evidence links, Checkov's result, the cut sentence, the fix table and apply hint, unknowns, and a details block with the tool trace, unchanged paths, coverage and timings.

## Why it matters

The comment is the main UI judges see. The stub result already carries candidates, so the whole comment can be built and polished on day one instead of in three passes.
