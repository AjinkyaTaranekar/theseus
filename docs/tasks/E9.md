# E9: Terraform patch renderer

**Lane:** Engine | **Stage:** Beat 2: Fix it | **Size:** M | **Needs first:** F2, F4 | **Branch:** `e9-render-tf`

## The feature

Turn a candidate's patch ops into edits on the `.tf` files, so the apply command and containment PRs commit real Terraform.

## Why it matters

"It acts" means a commit a reviewer can read, not a JSON blob. It needs only the op contract and the demo files, so it starts early and keeps A9 and FM6 off the critical path.
