# F1: Repo, board and CI

**Lane:** Foundation | **Stage:** Foundation | **Size:** S | **Needs first:** P5 | **Branch:** `f1-repo-skeleton`

## The feature

The runnable package skeleton that every other task builds on: package, settings, errors, CLI entry point, CI, templates, and the GitHub board. The repo already holds the agent kit (`AGENTS.md`, `docs/`, `tools/`).

## Why it matters

Every brief assumes `pytest -q`, `ruff check .` and `python -m theseus` work, and that CI checks every commit message.

## Steps

1. Clone the repo and turn on the commit check: `git config core.hooksPath .githooks`.
2. Write the files above, then `pip install -e .[dev]` and make CI pass locally.
3. Run `python tools/make_board.py --repo <owner>/theseus` to create labels (including `demo`), milestones, issues and the project.
4. Merge fast: F2 and F4 both start from this commit.

## Done when

- [ ] CI is green on the first PR
- [ ] `python -m theseus --help` lists the four commands
- [ ] `pytest -q` passes
- [ ] The GitHub board exists with every task as an issue
- [ ] `pytest -q` and `ruff check .` pass, and `AI_USE.md` has this task's line

## Out of scope

- Any engine, agent or API code
- Contracts (F2)
- The demo world (F4)
