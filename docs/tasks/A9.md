# A9: /theseus apply command

**Lane:** Agent and GitHub | **Stage:** Beat 2: Fix it | **Size:** M | **Needs first:** F7, E9 | **Branch:** `a9-apply`

## The feature

A reviewer's `/theseus apply <ID>` commits the rendered fix to the PR branch through the App, which re-triggers the analysis. Every commit is fenced to the world root.

## Why it matters

The agent acts, and only after a person approves. It needs only the renderer and the App, so it is built and tested with a hand-written candidate while E6 and A7 are still in progress.
